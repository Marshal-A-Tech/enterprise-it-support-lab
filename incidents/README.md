# Incident Reports

## Overview

This directory contains hands-on IT Support incident reports completed as part of the Enterprise IT Support Lab.

Each incident follows a structured troubleshooting methodology:

SYMPTOM → INFORMATION GATHERING → HYPOTHESIS → TEST → ROOT CAUSE → FIX → VERIFY → DOCUMENT
